# Prototipo DoveConviene (web)

Prototipo web de la app DoveConviene para probar diseños rápidamente y hacer tests A/B.

## Qué hay en esta carpeta

| Archivo | Para qué sirve |
|---|---|
| `index.html` | La estructura de la pantalla (cabecera, carrusel, tiendas, barra inferior) |
| `styles.css` | El aspecto visual. Arriba del todo están los **tokens** (colores, radios, tipografía) |
| `app.js` | Los datos de ejemplo (folletos y tiendas) y la lógica de la variante A/B |

## Verlo en tu ordenador

Haz doble clic en `index.html` y se abre en el navegador. Ya está.

Para ver la **variante B**, añade `?variante=b` al final de la dirección en el navegador.

## Subirlo a GitHub (sin usar código)

1. Entra en [github.com](https://github.com) e inicia sesión (o crea una cuenta).
2. Arriba a la derecha pulsa **+** → **New repository**.
3. Ponle de nombre `prototype-dc`, déjalo en **Public** o **Private** y pulsa **Create repository**.
4. En la página que aparece, pulsa el enlace **uploading an existing file**.
5. Arrastra **los archivos de dentro de esta carpeta** (no la carpeta entera) a la ventana.
6. Abajo pulsa **Commit changes**.

## Publicarlo como página web (para compartir un enlace)

1. En tu repositorio, ve a **Settings** → **Pages**.
2. En *Branch*, elige **main** y pulsa **Save**.
3. Espera 1–2 minutos y recarga: aparecerá un enlace tipo
   `https://TU-USUARIO.github.io/prototype-dc/`

> Si el repositorio es privado, GitHub Pages puede requerir un plan de pago o de empresa.

## Hacer cambios después

En GitHub, abre el archivo → icono del lápiz ✏️ → edita → **Commit changes**.
La página publicada se actualiza sola en un minuto.
